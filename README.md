# Project-2---arsitektur-jaringan-Enterprise-Collapsed-Core-
🔹 Segmentasi: 4 VLAN terpisah (Staff, Voice, IT, Server) dengan 802.1Q Trunking. 
🔹 High Availability: EtherChannel (LACP), STP anti-loop, dan backup gateway HSRP. 
🔹 Routing &amp; WAN: Routing dinamis OSPF Area 0 dan koneksi ISP Frame Relay. 
🔹 Server Terpusat: DHCP Relay, DNS, dan Web Server dalam segmen khusus VLAN 99.
